# 🏛️ Regla Maestra de Nube e Integraciones Oficiales — IMPROBEARS (Max C-00)

Este repositorio incluye el plugin oficial `.agents/plugins/improbears-cloud-suite` que viaja automáticamente a `☁️ Remote Conversations` (Nube de Google) y `🚀 Remote Control` (SSD Local).

## 🔌 APIs, Motores Generativos y Servicios en Nube Activos
1. **Google Flow / Veo 3.1 / Kie.ai / Fal.ai (`KIE_API_KEY`, `FAL_KEY`, `GEMINI_API_KEY`):**
   - Generación de video cinematográfico (Veo 3.1 / Google Flow), imágenes editoriales (Nano Banana 2 / Imagen 3) y audio.
2. **HeyGen API (`HEYGEN_API_KEY`):**
   - Avatares digitales hiperrealistas y voceros corporativos de ImproBears Studio.
3. **Stripe API (`STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY`, `STRIPE_WEBHOOK_SECRET`):**
   - Pasarela de pagos en vivo y webhooks para Acqua Ixtapa, TheBestBrand e ImproBears Ingredients.
4. **Zoho One API (`ZOHO_CLIENT_ID`, `ZOHO_CLIENT_SECRET`, `ZOHO_REFRESH_TOKEN`, `ZOHO_BOOKS_ORG_ID`):**
   - Integración directa con Zoho CRM, Zoho Bigin, Zoho Books (facturación CFDI 4.0 y Portal de Clientes) y Zoho Sign.
5. **Infraestructura Cloud 24/7 (Railway + Neon PostgreSQL 18 + Firebase + Cloudflare):**
   - **TheBestBrand API & Studio (Railway):** `https://thebestbrand-api-studio-production.up.railway.app`
   - **ImproBears Web Awwwards (Firebase):** `https://improbears-com.web.app`
   - **Acqua Ixtapa App (Cloudflare Workers):** `https://acquaixtapa.chorchcw.workers.dev`
   - **Neon PostgreSQL 18:** Proyectos `TheBestBrand` (`green-cherry-54371329`) y `AcquaIxtapa` (`flat-forest-31853658`).
